## 7 已核对且未发现问题的点

- **解压/归档路径安全**：safe_extract_path 对 ..、绝对路径、盘符、UNC、lexically_normal 兜底；gzip CRC32/ISIZE、zip/tar 1 GiB 上限；pkg 只在 stage 内找顶层目录。
- **包/仓库/依赖名**：validate_pkg_name 覆盖 install/remove/search/info/update 与 repo 命令；索引 prefix+file 组合再次 is_path_within。
- **哈希与锁**：sha256 大小写归一、sidecar 仅本地归档、明文 http 下载前确认、archive/lib hash 语义分离；lockfile JSON/TOML 迁移与 save/load 未发现新破坏（C-01/C-02 除外）。
- **配置合并**：内置 < global < user < CLI/env；[base_dir] 按 scope 保存；相对 config 文件目录、~、XDG、Windows 用户路径、--config 缺失致命、互斥与 exit 1 均正确。
- **并行与日志**：ThreadPool 异常传播；g_log_mutex 覆盖 info/warn/error；compile_times 每 worker 独立；record 只在 future 完成后单线程合并。
- **watch 去抖**：pending_paths/last_event 受锁保护、stop_requested 原子；忽略规则在 flush 再次应用（A-01 为退出生命周期问题）。
- **Lua 其余**：crypto NIST 向量与边界、i18n 430/430 全键、en/zh 占位符零差异、argparse 短选项聚合/-- 终止符/位置参数交错。
- **export/example/workspace scan**：原子写 + 覆盖保护 + cmake_quote；example 名精确匹配；scan 跳 hidden/symlink visited/嵌套 workspace/root 逃逸。

## 8 未覆盖与限制

- 集成测试因当前环境无法联网安装 catch2 未跑完；pre.1 最终门槛必须在 CI 或联网环境跑 bash build.sh test-all。
- 未做模糊测试/长期压力测试；并发安装（C-06）、watch 大输出（C-07）按静态证据定级。
- 审查以「当前实现」为基准；文档与实现冲突时，pre.1 按发布语义逐项裁定（见 pre 计划 §3.4）。

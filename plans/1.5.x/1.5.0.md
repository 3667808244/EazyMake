## 1 背景

1.5.0 的主题是**公共配置契约**：在项目级 ezmk.toml 之外新增**用户级 / 全局级 config.toml**，提供个人或整机默认值，同时保持 1.4.11 的行为作为默认。开发分四个波次：

1. **dev.1~dev.7 + pre.1**：配置加载/合并/校验、路径与工具定位、project-new 默认、日志、构建/测试/watch/pack/pkg 默认；pre.1 完成用户触达、全量文档、i18n 与 47 项审查收口（1219/6979）。
2. **dev.8~dev.11**：项目级 agent skills、编译器/连接器输出策略、工具链/缓存/网络/安装前缀配置、首次无配置运行生成全注释模板（1228/7095）。
3. **dev.12**：第二轮全量审核修复（阶段零 31 项 + A-01~A-24 收口），覆盖 Lua 资源上限、递归 watch、临时目录/原子写、linker/C 缓存、TOML 严格、i18n 清理、MSVC 实机验证（1242/7922）。
4. **pre.2**：dev.8~dev.12 聚合复核、pre.1 延后项重新裁定、文档/i18n/CHANGES、发布流水线预检与发布门槛预核对；C-02 预发布约束修复（1243/7928）。

现在进入最后一步：聚合为 **1.5.0 正式版**，按 workflow §3 执行冻结 → 版本/文档 → tag/Release → 三渠道分发 → 收尾。

### 3.3 tag 与 GitHub Release

- 提交发布准备（版本号 + CHANGES + 索引）并 push，确认 CI 绿。
- git tag v1.5.0 + git push origin v1.5.0。
- 创建 GitHub Release（**published** 状态触发 release.yml；仅 push tag 不触发 workflow）：
  - 标题 v1.5.0；说明引用 CHANGES 1.5.0 条目。
- 核对 Release 产物（[release.yml](.github/workflows/release.yml)）：
  - ezmk-windows-x64.zip（含 ezmk.exe / ezmk-lua.exe / _ezmk，**不含 man**）；
  - ezmk.exe + ezmk.exe.sha256；ezmk-lua.exe + ezmk-lua.exe.sha256；
  - ezmk-linux-x64.tar.gz（含 man/ 4 页 + _ezmk）；
  - ezmk-macos-arm64.tar.gz（含 man/）；
  - macos-x64 默认 skipped（ENABLE_MACOS_X64 未设，属预期）；启用时额外 1 个资产。
  - 对每个资产核对 digest 与 assets[].digest；解包后 ezmk version → 1.5.0。

### 3.4 三渠道分发

**Homebrew**
- 从 Release 资产取真实 sha256（gh api repos/<owner>/EazyMake/releases/tags/v1.5.0 的 assets[].digest）。
- 更新 publish/homebrew/ezmk.rb：version 1.5.0、linux / macos-arm64 URL 与 sha256；同步 Homebrew tap 仓库（homebrew-eazymake）并提交。
- brew install 冒烟：ezmk version、man ezmk.1 可读。

**winget**
- 新建 publish/winget/e/ezmk/1.5.0/ 三件套（version / installer / locale.en-US）；InstallerSha256 = ezmk-windows-x64.zip digest。
- 本机 winget validate；提交 microsoft/winget-pkgs PR（CLA/CI/版主审批为发布后跟进，不阻塞发布）。

**pacman**
- publish/arch/PKGBUILD：pkgver=1.5.0、sha256sums = v1.5.0 tag 源码 tarball digest。
- 本机 MSYS2 makepkg -fd 出包并验证：包含 ezmk.exe / ezmk-lua.exe / _ezmk / man 4 页；包内 ezmk version → 1.5.0。AUR 仍未开通，不提交。

**install 脚本**
- install.sh / install.ps1 对 v1.5.0 Release 冒烟（下载、sha256、PATH、man/zsh、ezmk version）。

### 3.5 验收与回滚

- 验收：三渠道 ezmk version = 1.5.0；man 渲染零告警；Windows 无 man；Linux/macOS 有 man；zsh 补全可加载；CHANGES/索引与 Release 一致。
- 回滚：任一渠道/资产校验失败 → 删除 Release 与 tag（gh release delete / git push --delete origin v1.5.0），修复后重新走 §3.3；**禁止**保留半发布状态。

## 5 兼容性

| 变更 | 影响 | 说明 |

| 公共 API | **无破坏性变更** | 破坏性变更仍归 2.0.0 |

## 6 已知限制 / 延后项

- macOS kqueue 递归分支未实机验证（Linux 已由 CI 覆盖）；macos-x64 Release job 默认 skipped。
- MSVC shared 模板未内置 __declspec(dllexport)，需自行导出才生成导入库。
- A-23（lockfile 批量保存）延后 2.0.0（已登记 plans/2.0.x/README.md）。
- C-06（并发安装锁）、C-07（workspace 输出缓冲）、C-12（repo 迁移部分失败）、D-06（子进程输出上限）延后 1.5.x 补丁线。
- 配置加载期诊断保持英文；[settings].editor 仍按单一可执行路径处理。
- CI ubuntu-latest 迁移提示已记录（pre.2），不阻塞发布。

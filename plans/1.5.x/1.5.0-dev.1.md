## 1 背景

当前用户可调默认值几乎全部硬编码：包 / 仓库 / install 前缀 / example 输出 / 构建目录 / 并行度 / 测试超时 / watch 去抖 / pack 默认 / 语言 / 颜色 / project new 行为 / 日志。要做两级 `config.toml`，必须先有一个**只读加载层**：知道配置在哪、怎么解析、怎么合并、错误怎么报；否则后续接入会各自为政。

本版不改变任何现有行为，只把「配置」这件事本身做成可靠的基础设施。

## 3 详细设计

### 3.1 环境变量与目录（C-01）

| 变量 | 作用 | Linux 默认 | Windows 默认 |
|------|------|-----------|--------------|
| `EZMK_GLOBAL_CONFIG_DIR` | 系统级配置目录 | `/etc/ezmk` | `C:\.ezmk\config` |
| `EZMK_USER_CONFIG_DIR` | 用户级配置目录 | `$HOME/.config/ezmk`（`XDG_CONFIG_HOME` 优先） | `$USERPROFILE\.ezmk\config` |

- 环境变量非空 → 原样使用；空 / 未设置 → 平台默认。
- Windows `$USERPROFILE` 回退复用 `util::get_home_dir()`。
- 目录不存在 = 没有该级配置；目录存在但 `config.toml` 解析失败 = 致命错误。

### 3.2 `config.toml` schema（C-02 / C-02b）

顶层只允许 `[base_dir]` 与 `[settings]`，其余键 / 表 fail-fast。本版定义**完整键集**；dev.2/3/6 只消费，不各自解析文件。

~~~toml
[base_dir]
installed_packages = "/var/ezmk/pkg"
examples           = "/usr/local/share/ezmk/examples"
repo_cache         = "/var/cache/ezmk/repo"
logs               = "/var/log/ezmk"

[settings]
natural_language = "auto"
color_mode       = "auto"        # auto|off|16colors|256colors|truecolor
color_theme      = "default"
log_level        = "info"        # off|error|warn|info|debug

auto_init_git    = true
gen_gitignore    = true
gen_readme       = true
initial_commit   = false         # bool 或 string
gen_agent_md     = false
default_project_type    = "executable"
default_language        = "C++17"
default_project_version = "0.1.0"
default_compile_flags   = ["-Wall", "-Wextra"]

build_dir        = "build"
default_jobs     = 0             # 0 = auto (hardware concurrency)
test_timeout     = 30            # seconds
test_report_dir  = ".ezmk/test-results"
watch_debounce_ms = 300
watch_ignore     = []
pack_format      = "tar.gz"
pack_output_dir  = "."
pack_name        = ""            # 空 = <name>-<version>
pack_exclude     = []
default_pkg_scope = "project"    # project|user|global
auto_install_deps = true
scan_skip_dirs   = []

git_path         = "git"
editor           = ""            # 空 = vim/nano/emacs 候选
auto_pack        = false
~~~

默认值语义与覆盖规则见 dev.2 / dev.3 / dev.6；本版只解析与保存。

### 3.3 合并顺序（C-03）

1. 内置默认。
2. 系统级 `$EZMK_GLOBAL_CONFIG_DIR/config.toml`。
3. 用户级 `$EZMK_USER_CONFIG_DIR/config.toml`（`--config` 指定的文件替代用户级，不叠加）。
4. CLI / 环境（本版只处理 `--config` / `--no-config`；`--lang` / `--color` 在 dev.3）。

`[base_dir]` 按作用域保存（系统级 → Global，用户级 → User），不做跨作用域覆盖；`examples` / `logs` 用户级覆盖系统级。

### 3.4 运行时结构与访问器（C-06）

~~~cpp
struct BaseDirConfig {
    std::optional<fs::path> installed_packages;
    std::optional<fs::path> repo_cache;
    std::optional<fs::path> examples;
    std::optional<fs::path> logs;
};
struct SettingsConfig {
    std::string natural_language = "auto";
    std::string color_mode = "auto";
    std::string color_theme = "default";
    std::string log_level = "info";
    bool has_initial_commit = false;
    bool initial_commit_enabled = false;
    std::string initial_commit_message;
    bool auto_init_git = true;
    bool gen_gitignore = true;
    bool gen_readme = true;
    bool gen_agent_md = false;
    std::string default_project_type = "executable";
    std::string default_language = "C++17";
    std::string default_project_version = "0.1.0";
    std::vector<std::string> default_compile_flags = {"-Wall", "-Wextra"};
    std::string build_dir = "build";
    int default_jobs = 0;
    int test_timeout = 30;
    std::string test_report_dir = ".ezmk/test-results";
    int watch_debounce_ms = 300;
    std::vector<std::string> watch_ignore;
    std::string pack_format = "tar.gz";
    std::string pack_output_dir = ".";
    std::string pack_name;
    std::vector<std::string> pack_exclude;
    std::string default_pkg_scope = "project";
    bool auto_install_deps = true;
    std::vector<std::string> scan_skip_dirs;
    std::string git_path = "git";
    std::string editor;
    bool auto_pack = false;
};
struct RuntimeConfig {
    SettingsConfig settings;
    BaseDirConfig global_dirs;
    BaseDirConfig user_dirs;
    fs::path global_config_file;
    fs::path user_config_file;
    bool loaded = false;
};
const RuntimeConfig& runtime_config();
void load_runtime_config(int argc, const char* const* argv);
void reset_runtime_config_for_test();   // 仅测试
~~~

- 加载幂等；未加载时 `runtime_config()` 返回默认值，保证现有单测直接调用不需先 `main`。
- 加载在 `cli::parse()` 之前（与现有 `--color` 预扫描同层）。

### 3.5 校验与安全

- 未知键 / 类型错误 / 非法 `log_level` / `color_mode` / `pack_format` / `default_pkg_scope` / `--config` 与 `--no-config` 冲突 → 带文件与键名的错误，退出非零。
- 不允许在用户级指定 `Project` 作用域路径；加载阶段不建目录、不写文件。
- 相对路径在 dev.2 解析；本版先保存原始字符串。

### 3.6 `--config` / `--no-config` 预扫描（C-07a）

- 在 `cli::parse()` 前扫描 `--config <file>`、`--no-config`；两者同时出现 → 报错。
- 预扫描不消费其它命令专属选项；正式解析仍保留这两个选项的帮助文案（dev.5 接 `--help`）。

### 3.7 已知坑位

| # | 坑 | 对策 |
|---|-----|------|
| 1 | 加载早于 CLI 解析 | 轻量预扫描，与 `--color` 同层 |
| 2 | 单测直接调用 `pkg`/`repo` | 未加载返回默认；测试 reset |
| 3 | 两级配置同名键 | 用户级覆盖系统级；`[base_dir]` 按作用域 |
| 4 | 未知键 fail-fast 破坏旧配置 | `--no-config` 逃生；CHANGES 写明 |

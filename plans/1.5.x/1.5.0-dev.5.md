## 3 详细设计

### 3.1 映射总表

| 全局键 | 项目级覆盖 | 默认 | 落点 |
|--------|------------|------|------|
| `default_jobs` | `[compile].jobs`（新增） | 0 = auto | build.cpp 的 num_jobs |
| `test_timeout` | `[test].timeout`（新增） | 30s | build.cpp 的 run_opts.timeout_sec |
| `test_report_dir` | `[test].report_dir`（新增） | 内置 .ezmk/test-results | build.cpp 的 report_path |
| `watch_debounce_ms` | `[watch].debounce_ms`（新增） | 300 | main.cpp 的 FileWatcher |
| `watch_ignore` | `[watch].ignore`（新增） | 空 | main.cpp 的 add_ignore_* |
| `pack_format` | `[pack].format`（新增） | tar.gz | build.cpp 的 pack_project |
| `pack_output_dir` | `[pack].output_dir`（新增） | . | 同上 |
| `pack_name` | `[pack].name`（新增） | 空 = name-version | 同上 |
| `pack_exclude` | `[pack].exclude`（新增） | 空 | 同上（叠加内置排除） |
| `default_pkg_scope` | — | project | cli.cpp 的 pkg install |
| `auto_install_deps` | `[pkg].auto_install`（新增） | true | pkg.cpp 的 AutoInstallTxn |
| `scan_skip_dirs` | `[workspace.options].scan_skip`（新增） | 空 | workspace.cpp 的 scan_dir |

### 3.2 构建并行度与产物命名

- 优先级：`-j/--jobs` > `[compile].jobs` > `[settings].default_jobs` > `hardware_concurrency()`。
- 0 表示 auto；负数报错；上限与 workspace 的 `default_jobs` 钳制一致。
- 产物命名：项目级 `[project].output_name` 优先，否则 `[project].name`；影响 executable / static / shared 的输出文件名（对象归档仍由 profile 的 `export_objs_path` 控制）。默认空 = 项目名，行为不变。

### 3.3 测试

- `[test].timeout` / 全局默认；0 表示不超时（明确文档）。
- `[test].report_dir` 只影响默认报告路径；`--report` 显式路径仍优先。

### 3.4 watch

- `debounce_ms` 下限 50ms、上限 5000ms（防误配）。
- `watch_ignore` 为额外前缀；内置 `build/` / `.ezmk/` / `.o/.d/.tmp` 仍生效。

### 3.5 pack

- `pack_format` 仅 `tar.gz` / `zip`（`tgz` 别名）；未知值 fail-fast。
- `pack_exclude` 为额外目录名 / 扩展名；内置 `build/.ezmk/.git` 与对象/二进制扩展名仍排除。
- `pack_name` 为空时保持 `<name>-<version>`；非空时直接作为归档 basename（不含扩展名）。

### 3.6 包管理

- `default_pkg_scope`：`pkg install` 未给 scope 时的默认；非法值 fail-fast。
- `auto_install_deps`：关闭时缺依赖直接报错并列出缺失项，不自动安装。

### 3.7 workspace scan

- `scan_skip_dirs` 追加到隐藏目录跳过规则；不影响嵌套 workspace / 符号链接逃逸检测。

### 3.8 已知坑位

| # | 坑 | 对策 |
|---|-----|------|
| 1 | `default_jobs` 过大 | 上限钳制（与 workspace 一致） |
| 2 | `test_timeout=0` 被误解 | 文档写明「0 = 不超时」 |
| 3 | pack 排除写错导致漏文件 | 内置排除仍生效；文档示例 |
| 4 | `auto_install_deps=false` 改变既有行为 | 默认 true，保持现状 |

## 3 详细设计

### 3.1 作用域绑定

| 配置来源 | 影响的 scope | 键 |
|----------|--------------|-----|
| 系统级 `config.toml` | `cli::Scope::Global` | `installed_packages` / `repo_cache` |
| 用户级 `config.toml` | `cli::Scope::User` | `installed_packages` / `repo_cache` |
| 用户级覆盖系统级 | 单值 | `examples` / `logs` |
| 项目 `ezmk.toml` > 全局 `[settings].build_dir` | 单项目 | `[project].build_dir` |

- **禁止**用户级 `installed_packages` 改 Global 作用域（提权面）。
- Project 作用域的包 / 仓库仍在 `<root>/.ezmk/...`，不受 `[base_dir]` 影响。

### 3.2 路径解析

- 绝对路径原样；相对路径相对**该 config.toml 所在目录**（项目级 `build_dir` 相对项目根）。
- 支持 `~` / `~/` / `~\`（复用 `[install].prefix` 规则）。
- 含 NUL / 无法规范化 → 配置错误。
- 加载阶段不创建目录。

### 3.3 `build_dir` 接入

把硬编码的 `build` 收敛为一个 helper（如 `config::build_dir(proj_root)`），替换：

- `src/build.cpp:700`（`st.build_dir`）、`:1356`（`obj_files.zip`）、`:1644-1645`（sibling 库）、`:1775`（pack）、`:1863`（pack 剪枝）、`:1972`（precompiled）、`:2731/2735`（test 报告）
- `src/compile_db.cpp:107`（对象根）
- `src/main.cpp:454`（watch 忽略）
- `src/project.cpp:75`（`project new` 创建）
- `src/lua_api.cpp:517`（`ezmk.build_dir()`）

策略：项目级 `[project].build_dir` 优先；否则全局 `[settings].build_dir`；否则 `"build"`。相对值相对项目根。

### 3.4 `git_path` / `editor`

- `git_path`：替换 `git_available` / `git_clone` / `git_pull` / `git init` 中的字面量 `git`（默认 `"git"`，即 PATH）。
- `editor`：非空时直接作为编辑器命令；空时沿用 `EDITOR` / `VISUAL` → vim/nano/emacs 候选。

### 3.5 已知坑位

| # | 坑 | 对策 |
|---|-----|------|
| 1 | 相对路径基准写成 CWD | 全局相对配置文件目录；项目级相对项目根 + 单测 |
| 2 | build_dir 替换漏点导致缓存/忽略错位 | 单一 helper + 全仓 grep 断言 |
| 3 | 旧路径与覆盖路径混合 | 未配置时走完全相同的旧分支 |
| 4 | git 路径含空格 | 复用 `quote_cli_arg` / `escape_shell_arg` |

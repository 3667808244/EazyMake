# EazyMake 1.5.0-dev.4 — 日志子系统

> **状态：📋 计划完成（2026-10-24，待实现）** —— 1.5.0 的第 4 个 dev 子版本。系列索引见 [README.md](README.md)。
>
> **依赖**：dev.1（配置）、dev.2（`logs` 目录）。**范围边界**：只做 `log_level` 过滤与可选文件日志；不改现有 stderr 文案格式。
>
> **⛔ 门槛**：同 dev.1；只读日志目录必须降级不报错。

## 1 背景

目前没有日志级别，也没有文件日志。`[settings].log_level` 与 `[base_dir].logs` 已在 dev.1/dev.2 解析，本版把它们变成实际行为。

## 2 目标

| # | 目标 | 优先级 |
|---|------|--------|
| C-08a | `log_level` 过滤 stderr（`error` 恒输出；`off` 仅 `fatal`） | P0 |
| C-08b | `<logs>/ezmk.log` 追加写（UTF-8 / 行缓冲 / mutex） | P1 |
| C-08c | 写入失败一次性警告后降级为仅 stderr | P0 |
| C-09c | 单测：级别过滤 / 只读目录降级 | P0 |

## 3 详细设计

### 3.1 级别

`off < error < warn < info < debug`。`fatal` 永远输出；`off` 仅保留 `fatal`。未知值在 dev.1 已 fail-fast。

### 3.2 文件日志

- 仅当 `log_level != off` 且 `logs` 已配置时启用。
- 追加写 `ezmk.log`；UTF-8；行缓冲；进程内 mutex。
- 不做轮转；文档注明。
- 写入失败：一次性 warning，关闭文件句柄，仅保留 stderr。

### 3.3 已知坑位

| # | 坑 | 对策 |
|---|-----|------|
| 1 | 只读 / 无权限目录 | 一次性警告后降级 |
| 2 | 多线程交错 | 复用现有输出 mutex |
| 3 | 日志影响退出码 | 日志失败不改变命令结果 |

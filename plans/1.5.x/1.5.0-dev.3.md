# EazyMake 1.5.0-dev.3 — 项目创建与行为默认值

> **状态：📋 计划完成（2026-10-24，待实现）** —— 1.5.0 的第 3 个 dev 子版本。系列索引见 [README.md](README.md)。
>
> **依赖**：dev.1（`RuntimeConfig`）。**范围边界**：语言 / 颜色 / `project new` 默认与模板默认值 / initial commit / auto_pack / gen_agent_md；**不做**日志（dev.4）与运行参数（dev.6）。
>
> **⛔ 门槛**：同 dev.1；每个开关必须有「默认 = 旧行为」测试。

## 1 背景

语言、颜色、`project new` 的 git / gitignore / readme / 初始提交、默认项目类型 / 语言 / 版本 / 编译 flags、auto_pack、agent.md 目前只能靠命令行或环境变量，或完全写死。本版把它们变成可配置默认值，并保留 CLI 最高优先。

## 3 详细设计

### 3.1 键与默认值

| 键 | 默认 | 行为 |
|----|------|------|
| `natural_language` | `auto` | `auto` 保持现状；其它值交给 i18n；`--lang` / `EZMK_LANG` 优先 |
| `color_mode` | `auto` | `auto` 现状；`off` = 永不；`16/256/truecolor` = 启用（本版同一 16 色 SGR） |
| `color_theme` | `default` | 预留主题名；本版仅 `default`，未知值 fail-fast |
| `auto_init_git` | `true` | 与未传 `--disable-git-init` 等价 |
| `gen_gitignore` | `true` | 与未传 `--disable-gitignore` 等价 |
| `gen_readme` | `true` | 新增开关，默认写 `README.md` |
| `initial_commit` | `false` | `false` 不提交；`true` 默认消息；string 作消息 |
| `gen_agent_md` | `false` | `project new` 生成 `AGENTS.md` 静态模板 |
| `default_project_type` | `executable` | `project new` 未传 `--type` 时的默认 |
| `default_language` | `C++17` | 写入新项目 `ezmk.toml` 的 `[project].language` |
| `default_project_version` | `0.1.0` | 写入新项目 `[project].version` |
| `default_compile_flags` | `["-Wall","-Wextra"]` | 写入新项目 `[compile].flags` |
| `auto_pack` | `false` | static 构建成功后 `project pack`；失败仅警告 |

### 3.2 `project new` 优先级

CLI `--type` / `--disable-git-init` / `--disable-gitignore` > `[settings]` 默认 > 内置默认。

- 类型 / 语言 / 版本 / flags 只影响**新生成**的 `ezmk.toml`；不改变已有项目。
- 模板内容（hello-world / 库骨架 / 固定 `.gitignore` / 空 README）本版仍为内置；**自定义模板目录**不在本版（后续独立评估）。

### 3.3 `initial_commit`

- 仅在 `auto_init_git` 生效且 `git_available` 时执行；失败仅警告。
- `true` → 默认消息；string → 原样作为消息。
- 默认 `false`，与 1.4.11 行为一致（当前 `project new` 不提交）。

### 3.4 `auto_pack`

- 只在顶层 `build_project` 成功后调用一次；加防重入标志。
- 仅 `project.type == "static"`；pack 失败 → 警告，不改构建退出码。
- `--no-auto-pack` 单次覆盖。

### 3.5 `gen_agent_md`

- 仅在 `project new` 时写 `AGENTS.md`；内容为静态构建 / 测试 / 目录说明；不覆盖已存在文件。

### 3.6 `color_mode` / `--color`

- 保留 `auto/always/never`；新增 `off`（=never）、`on/16colors/256colors/truecolor`（=always）。
- 256/truecolor 只记录偏好，当前输出仍为 16 色；文档写明。

### 3.7 已知坑位

| # | 坑 | 对策 |
|---|-----|------|
| 1 | `auto_pack` 递归 / 重复 | 顶层一次 + 防重入 |
| 2 | `initial_commit` 在无 git 时失败 | 先判 `git_available`，失败仅警告 |
| 3 | 语言设置覆盖 `EZMK_LANG` | 环境 / CLI 始终最高优先 |
| 4 | 模板默认值影响旧项目 | 只用于 `project new` 生成阶段 |

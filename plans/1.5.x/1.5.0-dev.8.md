## 1 背景

1.5.0-dev.3 已提供 `[settings].gen_agent_md`：设为 `true` 时，`ezmk project new` 会在新项目根写入一个最小 `AGENTS.md`（构建 / 测试 / 目录说明）。它解决的是「agent 读到项目说明」的问题，但没有解决「agent 读到可复用技能」的问题：技能需要独立目录、frontmatter 和更具体的命令表，不能塞进 `AGENTS.md` 冒充。

用户要求新增配置项 `[settings].gen_agent_skills`，让新项目可以选择生成项目级 agent skill。该能力应保持 opt-in、可预测、无副作用，并与 `gen_agent_md` 正交：可以只生成 AGENTS.md、只生成 skill、两者都生成，或都不生成。

## 3 详细设计

### 3.1 配置键

- 位置：`[settings]`，键名 `gen_agent_skills`（复数，与用户请求一致）。
- 类型：bool；默认 `false`。
- 作用域：全局级 / 用户级 config.toml；**不**提供项目级覆盖键（与 `gen_agent_md` 一致，避免项目自我授予生成权）。
- 合并：沿用 dev.1 的 global < user 逐键覆盖；显式 `--config` 替换用户级；`--no-config` 跳过两级。
- 校验：非 bool 报 `config field 'settings.gen_agent_skills' ... must be a boolean`；未知键仍由现有严格校验拒绝。
- 不新增 CLI 开关：本版只做配置项；如后续需要 `--gen-agent-skills/--no-gen-agent-skills`，另行立项。

### 3.2 生成目标与时机

- 目标文件：`<project>/.claude/skills/eazymake/SKILL.md`。
  - 选择 `.claude/skills` 是因为仓库现有技能目录与 Claude/兼容 agent 的约定一致；单技能目录名 `eazymake` 避免与未来复制的 `ezmk-user-*` 技能冲突。
  - 只生成一个技能文件，不生成 `.claude/settings.json`、不修改用户全局 skills。
- 时机：`create_project()` 完成 `ezmk.toml`、源码骨架、`AGENTS.md` 等既有写入之后，最后一步生成；失败按现有 `must_write` 规则 `fatal`，不留下「项目已创建」的成功假象。
- 目录：`fs::create_directories(root / ".claude/skills/eazymake")` 后再写文件。
- 幂等/覆盖：`project new` 的目标目录必须不存在（现有校验），因此正常路径无覆盖；仍按「文件已存在则跳过」防御，避免未来模板复用或测试夹具重复调用时覆盖用户内容。
- 与 `gen_agent_md` 正交：
  - `gen_agent_md=true, gen_agent_skills=false` → 只有 AGENTS.md；
  - `false,true` → 只有 skill；
  - `true,true` → 两者都有；skill 可引用 `AGENTS.md`，但不要求它存在。

### 3.3 skill 内容模板

生成内容为 UTF-8、LF、英文（agent-facing，不进 i18n），结构固定，便于测试与后续演进：

~~~markdown
---
name: eazymake
description: Build, test, package and manage this EazyMake C/C++ project.
---

# EazyMake project

## Project

- Name: <name>
- Type: <executable|static|shared|utils>
- Language: <C++17 etc>
- Version: <version>
- Build dir: <relative build dir>

## Commands

- Build: `ezmk build`
- Run: `ezmk run`
- Test: `ezmk test`
- Watch: `ezmk watch`
- Package: `ezmk pack`
- Install deps: `ezmk pkg install <pkg>`

## Rules

- Edit `ezmk.toml` for project settings; do not hand-edit generated build output.
- Prefer `ezmk` commands over direct compiler invocations.
- Keep tests under `test/`; run `ezmk test` before claiming success.
- Do not commit `build/`, `.ezmk/`, or generated artifacts.
~~~

约束：

- 不写入绝对路径、用户名、时间戳或随机数；同一输入生成字节一致内容。
- 项目名 / 类型 / 语言 / 版本 / 构建目录来自已解析的 `EzConfig` 与 `[settings].build_dir`，避免重复推导。
- 若项目类型为 `utils`，命令表仍保留 build/test/pack；不生成不存在的语言源码说明。
- 内容不包含 `gen_agent_md` 的全文副本，避免双份漂移；只引用 `AGENTS.md`（若存在）。

### 3.4 文档与 i18n

- `docs/zh/user_config.md` / `docs/en/user_config.md`：`[settings]` 表新增一行，默认 `false`，说明生成路径与 opt-in。
- `docs/zh/global_config.md` / `docs/en/global_config.md`：在「其余 `[settings]` 键」说明中覆盖（不重复完整表）。
- `man/ezmk.toml.5`：新增 `gen_agent_skills` 字段条目，默认 false；与 `gen_agent_md` 相邻。
- `scripts/check_config_docs.py`：自动覆盖新键（它从 `is_known_settings_key` / `parse_settings_table` 提取，无需硬编码）；跑闸门确认。
- `README.md` / `README_ZH.md`：无需新增章节；若配置速览提到 project-new 默认，补一句「可选生成 AGENTS.md 与 .claude/skills/eazymake/SKILL.md」。
- i18n：不新增用户界面键；生成文件是模板内容而非 UI 文案。若 i18n 检查因无变化而保持 436 键，属预期。

### 3.5 测试

- `test_config.cpp`：
  - 新键缺省为 false；
  - 显式 true / false 读入 `RuntimeConfig`；
  - 类型错误（字符串/整数）报错；
  - global 设 true、user 未设 → 继承 true；user 设 false → 覆盖为 false。
- `test_project.cpp`（扩展现有 gen_agent_md 用例）：
  - `gen_agent_skills=true` 时存在 `.claude/skills/eazymake/SKILL.md`；
  - 内容含 frontmatter、项目名、`ezmk build` / `ezmk test`、构建目录；
  - `false` 时不存在；
  - `gen_agent_md=true/false` 两两组合互不影响；
  - 生成文件为 LF、无绝对路径。
- 集成（`test_integration.cpp`，可选但推荐）：
  - 用 `--config` 指向含 `gen_agent_skills=true` 的 config，执行 `project new`，检查 skill 文件可被普通文本读取；不启动 agent。
- 文档闸门：`check_i18n.py` / `check_man_sync.py` / `check_docs_sync.sh` / `check_config_docs.py` / groff。

### 3.6 边界与已知取舍

| 项 | 取舍 |
|----|------|
| 已有项目 | 不自动补生成；只作用于 `project new`，避免在用户仓库里突然写文件 |
| 自定义技能 | 本版只生成一个内置 `eazymake` 技能；复制仓库 12 个技能或用户自定义模板不在本版 |
| 其他 agent 目录 | 只写 `.claude/skills`；不同时写 `.agents/skills` 等，避免多处漂移 |
| 覆盖策略 | 新项目无冲突；仍跳过已存在文件，不覆盖用户内容 |
| 安全 | 内容不含凭据/绝对路径；不执行任何 shell；生成失败走 `must_write` fatal |
| 语言 | 模板英文；不随 `natural_language` 翻译，避免 agent 指令漂移 |

## 5 兼容性

| 变更 | 影响 | 说明 |
|------|------|------|
| 新增 `[settings].gen_agent_skills` | 纯 opt-in | 默认 false，未配置时 `project new` 逐字节不变 |
| `project new` 生成 `.claude/skills/eazymake/SKILL.md` | 仅当显式开启 | 新项目目录原本不存在，无覆盖；不生成到用户全局 |

| 公共 API | 无破坏性变更 | 只新增配置键与模板文件 |
| i18n | 无新增键（预期） | 模板不进 UI 文案；若审计发现硬编码用户提示再补键 |

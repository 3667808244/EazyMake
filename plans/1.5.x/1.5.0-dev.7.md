## 3 详细设计

### 3.1 i18n

- 新增键：配置加载 / 校验错误 / 日志降级 / `--config` / `--no-config` / `--lang` 帮助。

- `scripts/check_i18n.py` 必须通过。

| 文档 | 内容 |
|------|------|
| `README.md` | 配置层速览 + 两个环境变量 |

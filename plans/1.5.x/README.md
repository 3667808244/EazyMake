# 1.5.x — 功能版本系列

> 1.5.x 系列 = **1.5.0 功能次版本**。当前仅首个 dev 子版本「用户/全局配置文件」已立项；其余 dev 子版本、`1.5.0-pre.N` 与正式发布聚合计划按用户后续补充（当前不创建）。

## 版本规划

| 子版本 | 主题 | 关键交付 | 状态 |
|--------|------|----------|------|
| [1.5.0-dev.1](1.5.0-dev.1.md) | 用户/全局配置文件 | 系统级 / 用户级两级只读 `config.toml`（`[base_dir]` 包 / 仓库 / example / 日志路径；`[settings]` 语言 / 颜色 / log_level / project new 默认 / auto_pack / gen_agent_md）+ 两个环境变量 + `--config` / `--no-config` / `--lang`；默认零变化 | 📋 计划完成（2026-10-24），待实现 |

## 定位

- **1.5.0 是 1.4.11 之后的第一个功能 minor**：新增「用户/全局配置层」这一公共契约，而不是继续压在 1.4.x 补丁线。
- **默认零变化**：未创建任何 `config.toml` 时，路径与行为与 1.4.11 完全一致；所有新能力 opt-in。
- **公共契约**：两个环境变量与 `[base_dir]` / `[settings]` 键名一经发布即稳定，新增键只能追加。

## 跨版本关注点

- 1.5.0 的其余内容、`pre` 与正式发布计划待补；本系列暂不影响 2.0.0 的破坏性变更窗口。
- 回归基线：1.4.11 发布态 **1169 用例 / 6788 断言 / 4 跳过 / 0 失败**。

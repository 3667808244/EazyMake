# EazyMake 1.3.6 — 代码质量收口（技术债清理）

> 1.3.0 正式发布后的**补丁版本**（1.3.x 系列补丁的延续）。主题来自 1.3.5 收口后的**代码质量分析**（`-Wall -Wextra` 仅 2 警告、测试:源码 ≈ 1.04:1、超长函数/重复逻辑/文案不一致等结论）——本版把分析中的**低成本高价值项**落地为可勾选阶段，纯重构与文案修复，**零新功能**。发布总览见 [`1.3.x/README.md`](README.md)。

---

## 1 背景

1.3.5 收口后对全库做了一次代码质量分析，结论摘要：

| 维度 | 现状 |
|------|------|
| 规模 | src ~16.3k 行 / include ~2.1k 行 / test ~17k 行（比例 ≈ 1.04:1） |
| 警告 | `-Wall -Wextra` 全库仅 **2 处**（`detect_catch2` 未用参数、`export.cpp:130` `&&`/`||` 缺括号） |
| 超长函数 | `run_tests()`（`build.cpp:1917-2471`，**~550 行**）单函数承载两框架 + 摘要解析 + 报告发射 |
| 重复逻辑 | `create_targz`/`create_zip` 的目录遍历+排序+`/` 分隔（Step 1）两份拷贝；`project run` 与 watch `--run` 的运行回显 ~10 行重复 |
| 文案不一致 | `parse_language` 报错 "Supported: 89, 99, 11, 14, 17, 20, 23" 缺 `98/03/26`（`ver_map` 实际支持） |
| 校验噪音 | `consumer_std_min()` 在消费者 `ezmk.toml` 非法时对**每个**包都 warn（多包项目刷屏） |
| 测试文件 | `test_integration.cpp` 3752 行、`test_config.cpp` 2037 行——单文件过大 |

**定位**：本版只做**零行为变化的清理与重构**——`-Wall -Wextra` 清零、文案与实现一致、去重、按框架/主题拆分。**不引入任何新 flag/配置/命令**；每个重构都有既有测试锁定行为（等价性/集成/全量回归）。

## 2 目标

| # | 目标 | 优先级 |
|---|------|--------|
| 1 | `-Wall -Wextra` 编译警告清零（2 处：未用参数 + 运算符括号） | P0 |
| 2 | `parse_language` 错误文案与 `ver_map` 一致（补全 98/03/26 或从 map 生成） | P0 |
| 3 | `consumer_std_min` 校验去噪：消费者配置非法时**每进程只 warn 一次** | P0 |
| 4 | 归档遍历共享：提取 `collect_stage_entries()`，`create_targz`/`create_zip` 复用（1.3.5 等价性测试锁定） | P0 |
| 5 | 运行逻辑共享：提取 `run_executable()` helper，`project run` 与 watch `--run` 复用（集成测试锁定） | P0 |
| 6 | `run_tests` **机械拆分**：按框架拆 helper（纯搬运，行为零变化；全量回归锁定） | P1 |
| 7 | 测试文件拆分：`test_integration.cpp` 按主题拆（helpers 提取共享头，纯组织） | P1 |
| 8 | **明确不做**：build.cpp/pkg.cpp 全面重构（1.4.0+）；cli.cpp 命令组拆文件（2.0.0 前）；Catch2 结构化解析（1.4.0）；1.3.1~1.3.5 延后功能项 | P0 |

## 3 详细设计

### 3.1 小修（目标 1/2/3）

| # | 位置 | 改法 |
|---|------|------|
| 1 | `build.cpp:1750` `detect_catch2(proj_root, depends)` | `depends` 参数无使用——删参（同步 `build.hpp` 声明与调用点）或 `[[maybe_unused]]`；选**删参**（无外部调用者，干净） |
| 2 | `export.cpp:130` `c >= '0' && c <= '9' \|\| c == '.'` | 补括号 `(c >= '0' && c <= '9') \|\| c == '.'`（逻辑本正确，纯可读性 + 消警告） |
| 3 | `config.cpp:373/379` 错误文案 | `ver_map` 含 `98/03/26` 但文案写 "Supported: 89, 99, 11, 14, 17, 20, 23"——改为从 `ver_map` 键生成列表（单一数据源，杜绝再次漂移）或补全文案 |
| 4 | `pkg.cpp:161` `consumer_std_min()` | 消费者 `language` 非法时每次调用都 warn——加 `static bool g_warned` 进程级去重（或仅对首次调用 warn）；多包项目只提示一次 |

### 3.2 归档遍历共享（目标 4）

- `util.cpp` 新增 `collect_stage_entries(source_dir)`：把 `create_targz`/`create_zip` 各自的 Step 1（递归遍历 → 相对路径 → `/` 分隔 → 目录尾 `/` → 排序）提取为共享 helper，返回 `std::vector<StageEntry{name, content, is_dir}>`；
- `create_targz` / `create_zip` 改为消费共享结果（zip 侧的组件级 `safe_zip_name` 校验保留，仍只作用于 zip 写侧）；
- **行为锁定**：1.3.5 的「tar.gz/zip 解包等价性」集成测试（`tree_hashes` 全量比对）重构前后必须全绿；另加 `collect_stage_entries` 单测（含子目录/空文件/排序）。

### 3.3 运行逻辑共享（目标 5）

- `main.cpp` 新增 `static void run_executable(const fs::path& exe, const std::vector<std::string>& args, bool warn_on_nonzero)`：
  - `running` i18n key + `"<exe>"` + 透传参数 + `run_command` + stdout/stderr 回显；
  - `warn_on_nonzero=false`（`project run`）：非零 → 返回退出码（现状）；
  - `warn_on_nonzero=true`（watch `--run`）：非零 → `watch_run_exit_nonzero` 警告不退出（现状）；
- `ProjectRun`（`main.cpp:194-213`）与 watch `run_watched_exe`（`:325`）都改调 helper；
- **行为锁定**：既有 `project run` 集成测试 + 1.3.4 的 watch `--run` 四类集成测试全绿。

### 3.4 `run_tests` 机械拆分（目标 6，P1）

- `run_tests`（`build.cpp:1917-2471`）当前结构：
  - 前置：项目根/build_dir/cache_dir、报告 spec 解析（1.3.2）、profile 应用、依赖包 include 收集、`cin` 组装（~120 行）
  - Catch2 分支（`:1968-2329`）：检测/生成 main/编译/链接/`-r` 透传/摘要文本解析（~360 行）
  - EZMK 分支（`:2332-2464`）：逐文件编译/链接/运行 + 记录收集 + JUnit 发射（~130 行）
- 拆为 3 个 static helper（**纯搬运，不改任何行为/变量名语义**）：
  - `prepare_test_compile_input(...)`：前置组装（返回 `cin`/`test_link`/`test_sources` 等）；
  - `run_catch2_tests(...)` / `run_ezmk_tests(...)`：两框架主体；
  - `run_tests` 变成薄调度（前置 + 按 framework 分发 + 未知框架 fatal）。
- **行为锁定**：全量 908 用例（含报告/过滤/缓存/失败门禁的既有覆盖）零回归；拆分后 `git diff -w` 可人工复核为纯搬运。

### 3.5 测试文件拆分（目标 7，P1）

- `test_integration.cpp`（3752 行）当前含大量 namespace 级 helper（`run_ezmk`/`find_ezmk_binary`/`write_ws_fixture`/`poll_log` 等）+ 全部集成场景；
- 新增 `test/test_integration_helpers.hpp`：提取共享 helpers（run_ezmk、ezmk_available、find_*、TempDir 相关、1.3.4 poll/kill、1.3.5 pack helpers…）；
- 按主题拆为 `test_integration_core.cpp`（build/run/clean/watch 基础）、`test_integration_pkg.cpp`（pack/install/repo）、`test_integration_workspace.cpp`（workspace）、`test_integration_report.cpp`（1.3.2/1.3.4 报告与 watch-run）等（**纯组织，测试行为零变化**）；
- **行为锁定**：拆分后全量 908 用例数量与断言数不变。

### 3.6 已知坑位与对策

| # | 坑 | 优先级 | 对策 | 落点 |
|---|-----|--------|------|------|
| 1 | 重构引入行为漂移（尤其 run_tests 拆分） | 高 | 机械搬运纪律：不改变量名/顺序/字符串；拆分后 `git diff -w` 复核 + 全量回归 | §3.4 |
| 2 | 共享 helper 签名变更影响未覆盖调用点 | 中 | `-Wall` 全量编译 + `grep` 全部调用点；删参需同步头文件声明 | §3.1/3.3 |
| 3 | `consumer_std_min` 去噪改变既有警告次数断言 | 低 | 检索测试是否断言警告次数；只加进程级去重不改首次语义 | §3.1 |
| 4 | 测试文件拆分丢失 helpers 可见性 | 中 | helpers 统一入共享头；按主题拆时先移 helper 再移用例 | §3.5 |
| 5 | 文案从 ver_map 生成后格式变化 | 低 | 生成函数输出保持原格式（", ".join）；既有文案断言检查 | §3.1 |

## 5 兼容性

|------|------|------|
| `detect_catch2` 删参 | 内部函数签名 | 同步 `build.hpp` 声明与唯一调用点；无外部调用者 |

| `run_tests` 拆分 | 内部重构 | 纯搬运；全量回归锁定 |
| 测试文件拆分 | 测试组织 | 用例/断言数不变 |
| 公共 API | **无破坏性变更** | 纯内部重构 + 文案修复，零新功能 |

## 6 跨版本关注点

- **纯内部补丁**：不引入新 flag/配置/命令/i18n key（可能微调文案）；`CHANGES.md` 无新 API 承诺。
- **与 1.4.0 的关系**：本版收掉质量分析中「低成本高价值」项；`run_tests` 的**语义级重构**（结构化解析、按报告事件流）与 build.cpp/pkg.cpp 全面重构归 1.4.0。
- **1.3.1~1.3.5 延后功能项不受影响**：`--run` 参数透传、`workspace watch`、`tgz` 别名、sha256 边车自动校验等仍归 1.4.0。
- **回归基线**：全量 908 用例 / 5283 断言（1.3.5 后实测），本版为重构版，**必须零回归**（含既有 2 个环境性跳过）。
- **i18n**：无新 key（文案修复不新增键）；`check_i18n.py` 维持 374 keys 一致。
- **后续窗口**：2.0.0 前可再评估 cli.cpp 命令组拆文件（`parse_*` 目前 1272 行单文件）。

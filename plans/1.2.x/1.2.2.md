# EazyMake 1.2.2 — 教程分类重组（子目录迁移）

> 1.2.x 稳定线补丁。发布总览见 [`1.2.x/README.md`](README.md)。

---

## 1 背景

教程目前 **14 章平铺**在 `tutorial/zh/` 与 `tutorial/en/` 根目录，索引是单一编号列表 1~14（`tutorial/zh|en/README.md`「章节」节），**没有分类**。14 章实际可归为四类主题，平铺结构让用户在索引里无法按主题跳转：

| 分组 | 章节 |
|------|------|
| 入门上手 | 01 安装 · 02 第一个项目 · 03 ezmk.toml · 04 缓存 · 05 profiles/并行 |
| 包管理 | 06 使用包 · 12 版本约束+lockfile · 13 第三方仓库 |
| 开发体验 | 07 监视/钩子 · 08 utils/cc · 09 测试 · 10 顶层别名 |
| 工具链互操作 | 11 CMake 导入 · 14 预编译共包 |

本版采用**方案2（文件级分类）**：把章节文件移入分类子目录，README 索引按分组展示。相比方案1（仅索引加分组标题），方案2 的目录结构即分类，用户直接按目录浏览。

## 2 目标

| # | 目标 | 优先级 |
|---|------|--------|
| 1 | 教程文件移入分类子目录（`basic/` 入门 · `packages/` 包管理 · `dev/` 开发体验 · `interop/` 互操作），**组内重新编号（每组从 01 起）**，zh/en 同步 | P0 |
| 2 | README 索引（`tutorial/zh|en/README.md`）改为**分组展示**（每组小标题 + 编号列表） | P0 |
| 3 | **全部既有链接保持有效**：README 高级特性表（教程 08/11/12/13/14）、`docs/zh/migrate-from-cmake.md`、教程内部相对引用与锚点（`01-install.md#windows原生无需-msys2` 等） | P0 |
| 4 | 中文为基准：先迁 `tutorial/zh/`，再同步 `tutorial/en/` | P0 |
| 5 | 文档收口：CHANGES.md 1.2.2 条目 + 系列 README 状态 | P1 |

### 3.2 关键决策

- **组内重新编号（每组从 01 起）**：编号反映分组位置（包管理第 2 章 = `packages/02-version-lockfile.md`），索引与引用更直观。代价：全部既有引用（README 高级特性表、docs、教程内部交叉引用、文字性「第 N 章」）需按**新旧文件映射表**（见 §3.3）重写——以「全仓 grep 零死链 + 零旧编号残留」为硬验收。
- **README 索引分组展示**：每组一个小标题（`### 入门` / `### 包管理` / `### 开发体验` / `### 工具链互操作`），组内按编号列表，保留「线性递进」说明（基础组按序阅读，进阶组按需阅读）。
- **README.md 文档表**（`[教程](tutorial/zh/)`）指向目录，无需改。
- **`docs/zh/migrate-from-cmake.md:80`** 的 `tutorial/zh/07-watch-hooks.md` → `tutorial/zh/dev/07-watch-hooks.md`（en 侧如有同款一并查改）。

## 5 兼容性

| 变更 | 影响 | 处理 |
|------|------|------|
| 教程文件路径 + 编号变化 | 外部书签/链接失效 | README/docs/教程内部按 §3.3 映射全部同步更新；历史文档不改（保留当时路径与编号） |
| 组内重新编号 | 引用全部重写 | 以新旧映射表为单一事实源；grep 零死链 + 零旧编号残留双验收 |
| 代码 / API | 零影响 | 纯文档重组 |
| 双语一致性 | 必须同步 | 中文为基准，先 zh 后 en，逐文件对照 |

## 6 跨版本关注点

- **1.2.2 为 1.2.x 稳定线文档补丁**：与 1.2.1（模板差异化）相互独立，可在 1.2.1 之后推进。
- **链接完整性与编号残留是最大风险**：以「全仓 grep `tutorial/(zh|en)/` 零死链 + 旧编号文件名零残留」为硬验收项（新旧映射见 §3.3）。
- **与 pre.2 的关系**：pre.2 新增了 12/13/14 与 README 高级特性表的教程链接——本次迁移后这些链接路径全部更新，README 高级特性表是主要联动点。
- **历史记录不改**：CHANGES.md、旧 plans 中的教程路径是当时事实，保留（避免改写历史）。

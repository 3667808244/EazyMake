# 0.x.x — 早期开发版本

> 0.x 系列版本计划（0.1.1 ~ 0.2.6）：从零实现到 i18n 命令行收尾，属于"从零搭建"开发阶段。**全部已完成 ✅**。其中 0.1.1 ~ 0.1.5 为历史回填（原文快照，出处见文末）。

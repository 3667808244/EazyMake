## 1 背景

- 1.1.2/1.1.3 已做 S1-S5 安全 + C1-C5 健壮性 + Q1-Q3 质量收口，但 1.2.0 系列（dev.1~dev.12）持续新增功能后，代码库出现新的质量债：`run_tests` 绕过单一事实源（命令注入面在 test 路径重新打开）、钩子路径无权限门控、编码事故残留（乱码固化进用户可见输出与测试运行时字符串）、一批校验缺失与死代码。
- dev.11 目标：**系统性收口**——安全不对称、高危正确性缺陷、编码事故、配置/CLI 校验、缓存/工具健壮性、死代码清理；每项修复带验收测试；公共 API 无破坏性变更。

## 3 详细设计

### 3.1 审查结论摘要（完整问题清单见 §7）

**🔴 高危（13）**：run_tests 注入面 + 对象列表空（build.cpp:1784-1904/1753-1766）；钩子无权限门控（lua_api.cpp:1008 vs 1184-1341）；Windows UTF-16 转换逐字节（file_watcher.cpp:124）；extract_string_array 静默丢弃（config.cpp:20-30）；import target_* 关键字泄漏（import.cpp:456-500）；export 预发布版本（export.cpp:124-126）；互依赖自动安装无界递归（pkg.cpp:938-962）；3 处空断言/自指 oracle e2e（test_integration.cpp:509-548/1417-1455/1695-1892）；编码事故 24+ 处（含运行时字符串）。

**🟡 中危（~40）**：symlink/junction 逃逸；沙箱黑名单缺 io/os；事务窗口缺口；dev.10 选择器两缺口；自动安装约束漏检；depfile 空格路径；stoul 溢出；export precompiled 硬编码 .a；pkg update 无 -y；watch 死代码；file_watcher 错误失明/macOS kqueue；缓存签名手工镜像（SDE 漏项）；build.cpp/util.cpp 巨型文件；config/repo 重复；CliArgs optional 不一致；版本约束无校验；default_profile 不交叉校验；clean 不解析参数；test -V 语义反；locked/no-lock 互斥；fmt 重扫；source_date_epoch 负值；targz 自产自销；lockfile 首文件选择；macOS 家族误判；cmd /c 转义集；下载无上限；MSVC 产物路径三处不一致。

**🟢 低危（~15）**：compare_version 预发布剥离；lockfile platform 硬编码；ThreadPool(0)；测试夹具 4 份重复；10 处 REQUIRE(true)；watch 测试 taskkill 机器级；增量缓存断言逃生门；进程拆分（见延后项）。

### 3.2 关键设计决策

| 决策 | 说明 |
|------|------|
| run_tests 复用单一事实源 | 编译走 `cache::build_compile_args` + `join_shell_args`（含 S4 黑名单）+ `toolchain::translate_compile_flags`；`project_objs` 由 `make_compile_input` 的 sources 推导或递归遍历；test_filter 经 `escape_shell_arg`——注入面、MSVC 翻译、包 include、缓存一次解决 |
| 钩子信任模型二选一 | 优先「安装钩子加载 perms + 上下文门控」（与 utils 同级信任，恶意包 preinstall 不再无提示读任意路径）；若选「钩子=完全信任」则必须改 docs/safety.md + 修 `lua_api.cpp:51-52` 注释（当前是无声不对称，不可接受） |
| 词法路径检查升级 | `path_within`/`norm_path` 检查前用 `fs::weakly_canonical` 解析（Windows junction 亦生效）；拒绝含链接逃逸的路径 |
| 配置校验前移 | 类型错误/非法版本/非法约束在 `parse_config` 抛（i18n key），不再静默吞或拖到 build 深处 |
| 事务安装 `.new` 换位 | 先拷贝到 `<name>.new` 再换位（旧→backup、new→旧），拷贝窗口内旧版始终存在；回滚 ec 检查；backup 改隐藏唯一名 |
| 每项修复带验收测试 | 注入回归、symlink 逃逸、含空格 depfile、长路径往返、约束回读、互依赖护栏等全部落测试，防 1.1.3 式「修了又开」 |

## 6 跨版本关注点

- **承接 1.1.2/1.1.3 安全收口**：本版修复的是后续功能引入的新缺口（test 路径注入、钩子不对称），沿用 S/C/Q 编号精神但不强行对应。
- **与 dev.10 联动**：dev.10 选择器的两处缺口（lib/ 缺失、MSVC 平局）在本版修；export precompiled 对接 dev.10 命名。
- **与 pre.1/pre.2 独立**：不碰发布流水线与 README 整理。
- **i18n X-macro**：新增 config_err_* / 权限相关 key 走 .def + 双 JSON。
- **回归基线**：全量测试零回归（dev.10 后 747 用例 / 3442 断言），作为硬门槛。

## 7 延后项（P2，明确收口）

- **大规模拆分**：`build.cpp`（test_runner/install/pack）与 `util.cpp`（archive/download）拆分、`process_installed_pkg` 拆分——属结构性重构，混入行为修复会放大回归面；收口到 dev.11 之后的独立子版本或 1.2.0 发布窗口（以「每阶段可验证」为原则）。
- **语义取舍**：`compare_version` 预发布剥离（文档化记录，确认仓库索引不产出预发布）；lockfile platform 字段删除。
- **测试卫生**：测试夹具统一（test_helpers.hpp）、REQUIRE(true) 清理、watch 测试 PID 化、增量缓存断言收紧——可随各阶段顺带或延后。
- **macOS kqueue 逐文件语义**：FSEvents 重写为独立工作项（macOS runner 长期无分配，先文档化 + 断言修正）。

# EazyMake 1.2.0-dev.3 — 默认项目模板内建 Debug/Release Profile

> 本计划并入 1.2.0 正式发布版。发布总览见 [`1.2.0.md`](1.2.0.md)。

---

## 1 背景

`ezmk project new` 通过 `config::write_default_config()`（`src/config.cpp`）生成的默认 `ezmk.toml` 目前只有基准 `[compile].flags = ["-Wall", "-Wextra", "-O2"]`，没有内建任何构建 profile。用户想获得 Debug / Release 两种构建形态，需要自行查阅 `docs/config_file.md` 手写 `[compile.profile.*]` 段——对新手不友好，也容易写错（如漏掉 `msvc_flags`）。

`[compile.profile.<name>]` 机制（0.2.3+）与文档中的 Debug/Release 示例早已存在，缺的只是**把它固化进默认模板**：让新项目开箱即有 Debug / Release 两个 profile，`ezmk build --profile debug|release` 直接可用。

同时修正一个与 profile 体系相悖的现状：当前基准 `-O2` 隐含"默认即优化"，但有了显式 profile 后，"优化级别属于 profile"才是清晰语义——基准应只保留通用警告标志。

## 3 详细设计

### 3.1 目标模板（`write_default_config()` 变更）

`src/config.cpp:739` 的 `write_default_config()` 生成内容变更为：

```toml
[project]
name = "<name>"
type = "<type>"
version = "0.1.0"
language = "C++17"

[compile]
flags = ["-Wall", "-Wextra"]
include_dirs = ["include"]

[compile.profile.debug]
flags = ["-g", "-O0"]
msvc_flags = ["/Zi", "/Od"]

[compile.profile.release]
flags = ["-O2", "-DNDEBUG"]
msvc_flags = ["/O2", "/DNDEBUG"]

[link]
flags = []
link_dirs = []
system_target = []

[depends]
lib = []
```

`type = "utils"` 时仍追加 `[utils] tools = []`（与现状一致）。

**要点**：

- **基准只留警告**：移除 `-O2`。无 `--profile` 的默认构建 = `-Wall -Wextra`（警告全开、无优化），优化级别由 profile 显式决定。
- **debug**：GCC/Clang `-g -O0`（可调试、不优化），MSVC `/Zi /Od`。
- **release**：GCC/Clang `-O2 -DNDEBUG`（优化 + 关闭断言），MSVC `/O2 /DNDEBUG`。
- **不内建 `[link.profile.*]`**：链接 profile 为空 `flags = []` 时与缺省等价，模板不加无意义空段；用户有链接专属 profile 标志（如 `-flto`）时自行追加。
- **不内建 profile macros**：如 debug 注入 `DEBUG=1` 等为可选增强，用户按需在 `[compile.profile.<name>.macros]` 追加，模板保持最小。

### 3.2 profile 语义对齐

- 合并规则不变（`docs/config_file.md`）：profile `flags`/`msvc_flags` **追加**到 base 之后。
- 因基准已无 `-O*`，profile 与 base 之间不存在 `-O2`/`-O0` 先后覆盖歧义：
  - `--profile debug` → `-Wall -Wextra -g -O0`
  - `--profile release` → `-Wall -Wextra -O2 -DNDEBUG`
- `--profile` 同时作用于 compile 与 link；无 link profile 时链接沿用基准（空）。

### 3.3 行为变更说明（需在 CHANGES.md 明确）

| 变更 | 影响范围 | 说明 |
|------|----------|------|
| 基准 `-O2` 移除 | **仅新建项目** | 旧项目 `ezmk.toml` 不被改写，行为不变 |

## 6 跨版本关注点

- **与 dev.2（CMake 导出）协同**：默认模板内建 profile 后，`ezmk project export cmake --profile release` 能直接导出与 ezmk 构建一致的优化配置；dev.2 的 profile 映射（P2）受益于新模板自带 `[compile.profile.*]`。
- **与 dev.1（compile_commands）协同**：`ezmk project cc --profile release` 生成的索引命令与 `ezmk build --profile release` 一致——模板自带 profile 使这一对照开箱即可验证。
- **dogfooding**：本次改动后，新项目模板即 EazyMake 自身推荐的工程化默认；文档示例与模板保持同源风格。
- **基准语义收敛**：`-O2` 从基准移除是一次性语义收敛（优化归 profile），后续新增优化类基准标志时应避免回填。

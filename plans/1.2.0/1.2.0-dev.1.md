# EazyMake 1.2.0-dev.1 — `ezmk project cc` 命令

> 本计划并入 1.2.0 正式发布版。**范围调整**：核心重构（`build_compile_args()`）+ 拦截 `ezmk utils cc` + `[compile].compile_commands` 自动生成已移入 **[`../1.1.x/1.1.1.md`](../1.1.x/1.1.1.md)**（1.1.1 补丁）；本计划仅覆盖 `ezmk project cc` 命令交付 + `ezmk utils cc` 弃用。

---

## 1 背景

1.1.1 已把编译命令构造收敛为**单一事实源**（`build_compile_args()` / `join_shell_args()` 重构 + `compile_db` 模块），并**拦截** `ezmk utils cc` 改由内置 C++ 生成器服务，修复了原有 Lua 工具的 compile_commands.json 命令 drift。

1.2.0 在其上补齐最后一步：新增**正式命令** `ezmk project cc`——内置 CLI 入口、零外部包依赖，不再需要 `ezmk-official-utils`。同时把 `ezmk utils cc` 从"拦截"过渡到"弃用提示"（2.0.0 移除）。

> 自动生成（`[compile].compile_commands`）已在 **1.1.1** 交付，本版不重复。

## 3 详细设计

### 3.0 前置基础（1.1.1 已交付，本版复用不改）

- `cache::build_compile_args()` / `join_shell_args()`（`src/cache.cpp`）
- `compile_db::generate_compile_db()`（`src/compile_db.cpp`）：遍历 sources → `build_compile_args()` → 规范化（去 `-MMD`/`-MF`/`-frandom-seed`/`/showIncludes`）→ 排序 → 原子写 JSON
- `Command::Utils` 对 `utils_name == "cc"` 的拦截（`src/main.cpp`）

### 3.1 命令

```
ezmk project cc                      # 输出 <proj_root>/compile_commands.json
ezmk project cc -o custom.json       # 自定义输出路径（相对项目根解析）
ezmk project cc --profile debug      # 应用 build profile 的标志/宏
```

| 项 | 值 |
|---|---|
| 命令枚举 | `Command::ProjectCc` |
| 命令形式 | `ezmk project cc`（`project` 子命令，与 `build`/`run`/`clean` 同级） |
| flags | `-o/--output <path>`（默认 `<proj_root>/compile_commands.json`）、`--profile <name>` |

- `main.cpp` 分发：新增 `Command::ProjectCc` 分支，调用 `compile_db::generate_compile_db()`（与 1.1.1 拦截共用同一实现）。
- 不新增顶层别名/简写（避免 `ezmk cc` 与 C 编译器歧义，保持与用户指定的命名一致）。

### 3.2 输出格式

沿用 1.1.1 `compile_db` 输出：`arguments` 数组（clangd 推荐，免 shell 双重转义）；`file` 相对项目根、`directory` 项目根绝对路径；按 `rel_src` 字典序；temp → rename 原子写。本版对生成器核心**零改动**。

### 3.3 `ezmk utils cc` 弃用（1.2.0 声明）

- **声明时机**：**1.1.1 未声明废弃**——其 CHANGES.md 仅表述为「优化 compile_commands.json 生成算法」（拦截是内部实现，`ezmk-official-utils` 的 `cc` 工具在 1.1.1 无任何废弃标识）。**本版（1.2.0）才正式声明废弃**。
- 1.1.1 的拦截在 1.2.0 迁移为新命令入口后，`Command::Utils` 对 `cc` 的处理改为输出弃用提示并转调 `project cc` 逻辑：

  ```
  [ezmk warn] `ezmk utils cc` is deprecated since 1.2.0 — use `ezmk project cc` instead.
  ```

- **包侧声明**：`ezmk-official-utils/utils/cc.lua` 的 `help()` 标注 `@deprecated since 1.2.0`；包 README 同步；`ezmk-official-utils` 包版本随声明提升（1.1.0 → 1.2.0）。
- 工具保留可用（不破坏现有脚本）；2.0.0 移除。

## 6 跨版本关注点

- **1.1.1 → 1.2.0 承接**：1.1.1 的 `Command::Utils` 拦截在 1.2.0 迁移为 `Command::ProjectCc`，`ezmk utils cc` 转弃用提示；共享 `build_compile_args()` + `compile_db` 单一事实源。
- **2.0.0 破坏性窗口**：`ezmk utils cc` 工具移除在 2.0.0 执行，1.2.0 只弃用不删。
- **`--profile` 一致性**：`project cc --profile` 应用逻辑须与 `build.cpp` 一致，避免"构建用 profile、索引不用"。
- **三个入口同一实现**：拦截（1.1.1）/ 自动生成（1.1.1）/ `project cc` 命令（本版）共用 `generate_compile_db()`，输出永远一致。
